### 1.2. `quiz_attempts`

| Column           | Type             | Constraints                                                                                                                  |
| ---------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `id`             | `bigint`         | `PRIMARY KEY` (generated)                                                                                                    |
| `user_id`        | `uuid`           | `NOT NULL`, `REFERENCES auth.users(id) ON DELETE CASCADE`                                                                    |
| `mode`           | `attempt_mode`   | `NOT NULL`                                                                                                                   |
| `level`          | `jlpt_level`     | Nullable in _Need-review_ mode; `CHECK ((mode = 'level' AND level IS NOT NULL) OR (mode = 'need_review' AND level IS NULL))` |
| `question_count` | `smallint`       | `NOT NULL`, `CHECK (question_count > 0)`                                                                                     |
| `status`         | `attempt_status` | `NOT NULL`, `DEFAULT 'in_progress'`                                                                                          |
| `score_percent`  | `numeric(5,2)`   | Nullable until completed                                                                                                     |
| `time_taken_ms`  | `integer`        | Nullable until completed                                                                                                     |
| `created_at`     | `timestamptz`    | `NOT NULL`, `DEFAULT now()`                                                                                                  |
| `completed_at`   | `timestamptz`    | Nullable                                                                                                                     |

Additional constraints

- `CHECK ((status = 'completed') = (completed_at IS NOT NULL))` – completed attempts must have a timestamp.

### 1.3. `quiz_questions`

| Column                | Type                                                                                                                    | Constraints                                                  |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `id`                  | `bigint`                                                                                                                | `PRIMARY KEY`                                                |
| `quiz_attempt_id`     | `bigint`                                                                                                                | `NOT NULL`, `REFERENCES quiz_attempts(id) ON DELETE CASCADE` |
| `kanji_id`            | `integer`                                                                                                               | `NOT NULL`, `REFERENCES kanji(id)`                           |
| `sequence`            | `smallint`                                                                                                              | `NOT NULL` – 1-based order in attempt                        |
| `question_stage`      | `question_stage`                                                                                                        | `NOT NULL`                                                   |
| `accepted_answers`    | `jsonb`                                                                                                                 | `NOT NULL` – array of valid lowercase strings                |
| `user_answer`         | `text`                                                                                                                  | Nullable until answered                                      |
| `answered_at`         | `timestamptz`                                                                                                           | Nullable until answered                                      |
| `need_review_toggled` | `boolean`                                                                                                               | Nullable                                                     |
| `is_correct`          | `boolean GENERATED ALWAYS AS (user_answer IS NOT NULL AND lower(trim(user_answer))::jsonb \<@ accepted_answers) STORED` |                                                              |
| `created_at`          | `timestamptz`                                                                                                           | `NOT NULL`, `DEFAULT now()`                                  |

Additional constraints

- `UNIQUE (quiz_attempt_id, sequence)` – exactly one row per position.
- `UNIQUE (quiz_attempt_id, kanji_id, question_stage)` – prevents duplicates.
- `CHECK ((answered_at IS NOT NULL) = (user_answer IS NOT NULL))`.

### 1.5. `user_quiz_stats` _(materialized view)_

Aggregates per-user performance. Created as:

```sql
CREATE MATERIALIZED VIEW user_quiz_stats AS
SELECT
  qa.user_id,
  COUNT(*)               AS total_attempts,
  AVG(qa.score_percent)  AS avg_score,
  MAX(qa.created_at)     AS last_attempt_at
FROM quiz_attempts qa
WHERE qa.status = 'completed'
GROUP BY qa.user_id;
```

Refresh nightly via `pg_cron`:

```sql
SELECT cron.schedule('0 3 * * *', $$ REFRESH MATERIALIZED VIEW CONCURRENTLY user_quiz_stats $$);
```

## 2. Relationships

1. **auth.users (1) — (N) quiz_attempts** via `quiz_attempts.user_id`.
2. **quiz_attempts (1) — (N) quiz_questions** via `quiz_questions.quiz_attempt_id`.
3. **kanji (1) — (N) quiz_questions** via `quiz_questions.kanji_id`.
4. **auth.users (M) — (M) kanji** through **need_reviews** (`PRIMARY KEY (user_id, kanji_id)`).

Cardinalities are enforced by foreign keys and unique constraints.

## 4. Row-Level Security (RLS) Policies

Enable RLS on user-scoped tables:

```sql
ALTER TABLE quiz_attempts   ENABLE ROW LEVEL SECURITY;
ALTER TABLE quiz_questions ENABLE ROW LEVEL SECURITY;
ALTER TABLE need_reviews    ENABLE ROW LEVEL SECURITY;
```

Policies (same pattern for `INSERT`, `UPDATE`, `DELETE`):

```sql
-- quiz_attempts
CREATE POLICY select_own_quiz_attempts
  ON quiz_attempts
  FOR SELECT
  USING (user_id = auth.uid());

CREATE POLICY modify_own_quiz_attempts
  ON quiz_attempts
  FOR ALL USING (user_id = auth.uid())
  WITH CHECK (user_id = auth.uid());

-- quiz_questions
CREATE POLICY select_own_quiz_questions
  ON quiz_questions
  FOR SELECT
  USING (
    EXISTS (
      SELECT 1 FROM quiz_attempts a
      WHERE a.id = quiz_questions.quiz_attempt_id
        AND a.user_id = auth.uid()
    )
  );

CREATE POLICY modify_own_quiz_questions
  ON quiz_questions
  FOR ALL USING (
    EXISTS (
      SELECT 1 FROM quiz_attempts a
      WHERE a.id = quiz_questions.quiz_attempt_id
        AND a.user_id = auth.uid()
    )
  ) WITH CHECK (TRUE);

-- need_reviews
CREATE POLICY select_own_need_reviews
  ON need_reviews
  FOR SELECT USING (user_id = auth.uid());

CREATE POLICY modify_own_need_reviews
  ON need_reviews
  FOR ALL USING (user_id = auth.uid())
  WITH CHECK (user_id = auth.uid());
```

`kanji` is read-only and left **public** for `SELECT`.

## 6. Additional Notes

- **Data integrity** — `quiz_attempts` ➝ `quiz_questions` count validated via application layer or a deferred trigger comparing `question_count` to `COUNT(*)`.
- **Soft-archive kanji** — future dataset changes set `is_active = false`, keep history untouched.
