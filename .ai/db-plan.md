# Kanji Quiz – PostgreSQL Database Schema

## 1. Tables, Columns & Constraints

### 1.0. `users` _(application view of `auth.users`)_

This table is managed by Supabase Auth.

| Column               | Type          | Constraints                 |
| -------------------- | ------------- | --------------------------- |
| `id`                 | `uuid`        | `PRIMARY KEY`               |
| `email`              | `char(255)`   | `NOT NULL`, `UNIQUE`        |
| `encrypted_password` | `char`        | `NOT NULL`                  |
| `created_at`         | `timestamptz` | `NOT NULL`, `DEFAULT now()` |
| `last_login_at`      | `timestamptz` | Nullable                    |

---

### 1.1. `kanji`

| Column       | Type          | Constraints                                                 |
| ------------ | ------------- | ----------------------------------------------------------- |
| `id`         | `integer`     | `PRIMARY KEY` (generated by sequence)                       |
| `character`  | `char(1)`     | `NOT NULL`,                                                 |
| `level`      | `jlpt_level`  | `NOT NULL`                                                  |
| `readings`   | `jsonb`       | `NOT NULL` – array of strings _(e.g. `["こう", "ぎょう"]`)_ |
| `meanings`   | `jsonb`       | `NOT NULL` – array of strings _(e.g. `["go", "conduct"]`)_  |
| `created_at` | `timestamptz` | `NOT NULL`, `DEFAULT now()`                                 |

---

### 1.2. `quiz`

| Column           | Type           | Constraints                                                                                                                  |
| ---------------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `id`             | `bigint`       | `PRIMARY KEY` (generated)                                                                                                    |
| `user_id`        | `uuid`         | `NOT NULL`, `REFERENCES auth.users(id) ON DELETE CASCADE`                                                                    |
| `type`           | `quiz_type`    | `NOT NULL`                                                                                                                   |
| `level`          | `jlpt_level`   | Nullable in _Need-review_ mode; `CHECK ((mode = 'level' AND level IS NOT NULL) OR (mode = 'need_review' AND level IS NULL))` |
| `question_count` | `smallint`     | `NOT NULL`, `CHECK (question_count > 0)`                                                                                     |
| `status`         | `quiz_status`  | `NOT NULL`, `DEFAULT 'in_progress'`                                                                                          |
| `score_percent`  | `numeric(5,2)` | Nullable until completed                                                                                                     |
| `created_at`     | `timestamptz`  | `NOT NULL`, `DEFAULT now()`                                                                                                  |
| `completed_at`   | `timestamptz`  | Nullable                                                                                                                     |

Additional constraints

- `CHECK ((status = 'completed') = (completed_at IS NOT NULL))` – completed quiz must have a timestamp.

---

### 1.3. `quiz_questions`

| Column          | Type            | Constraints                                         |
| --------------- | --------------- | --------------------------------------------------- |
| `id`            | `bigint`        | `PRIMARY KEY`                                       |
| `quiz_id`       | `bigint`        | `NOT NULL`, `REFERENCES quiz(id) ON DELETE CASCADE` |
| `kanji_id`      | `bigint`        | `NOT NULL`, `REFERENCES kanji(id)`                  |
| `sequence`      | `smallint`      | `NOT NULL` – 1-based order in quiz                  |
| `question_type` | `question_type` | `NOT NULL`                                          |
| `user_answer`   | `text`          | Nullable until answered                             |
| `answered_at`   | `timestamptz`   | Nullable until answered                             |
| `is_correct`    | `boolean`       | Nullable until answered                             |
| `created_at`    | `timestamptz`   | `NOT NULL`, `DEFAULT now()`                         |

Additional constraints

- `UNIQUE (quiz_id, sequence)` – exactly one row per position.
- `UNIQUE (quiz_id, kanji_id, question_type)` – prevents duplicates.
- `CHECK ((answered_at IS NOT NULL) = (user_answer IS NOT NULL))`.

## 2. Relationships

1. **auth.users (1) — (N) quiz** via `quiz.user_id`.
2. **quiz (1) — (N) quiz_questions** via `quiz_questions.quiz_id`.
3. **kanji (1) — (N) quiz_questions** via `quiz_questions.kanji_id`.
4. **auth.users (M) — (M) kanji** through **need_reviews** (`PRIMARY KEY (user_id, kanji_id)`).

Cardinalities are enforced by foreign keys and unique constraints.

## 4. Row-Level Security (RLS) Policies

Enable RLS on user-scoped tables:

```sql
ALTER TABLE quiz_attempts   ENABLE ROW LEVEL SECURITY;
ALTER TABLE quiz_questions ENABLE ROW LEVEL SECURITY;
ALTER TABLE need_reviews    ENABLE ROW LEVEL SECURITY;
```

Policies (same pattern for `INSERT`, `UPDATE`, `DELETE`):

```sql
-- quiz_attempts
CREATE POLICY select_own_quiz
  ON quiz
  FOR SELECT
  USING (user_id = auth.uid());

CREATE POLICY modify_own_quiz
  ON quiz
  FOR ALL USING (user_id = auth.uid())
  WITH CHECK (user_id = auth.uid());

-- quiz_questions
CREATE POLICY select_own_quiz_questions
  ON quiz_questions
  FOR SELECT
  USING (
    EXISTS (
      SELECT 1 FROM quiz_attempts a
      WHERE a.id = quiz_questions.quiz_attempt_id
        AND a.user_id = auth.uid()
    )
  );

CREATE POLICY modify_own_quiz_questions
  ON quiz_questions
  FOR ALL USING (
    EXISTS (
      SELECT 1 FROM quiz_attempts a
      WHERE a.id = quiz_questions.quiz_attempt_id
        AND a.user_id = auth.uid()
    )
  ) WITH CHECK (TRUE);

-- need_reviews
CREATE POLICY select_own_need_reviews
  ON need_reviews
  FOR SELECT USING (user_id = auth.uid());

CREATE POLICY modify_own_need_reviews
  ON need_reviews
  FOR ALL USING (user_id = auth.uid())
  WITH CHECK (user_id = auth.uid());
```

`kanji` is read-only and left **public** for `SELECT`.
